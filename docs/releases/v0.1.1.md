# todobem v0.1.1

A fix release. Upgrade from v0.1.0 with `todobem upgrade`, then restart todobem.

## Fixed

- **The UI shows the version you run.** The sidebar and the page footer said "todobem / 0.2"
  whatever the binary was; they now show the version the server names on its answers
  (`X-Todobem-Version`) — `v0.1.1` for this release, `dev-<rev>` for a build from a clone.

## Install or upgrade

```sh
todobem upgrade                                                                          # from v0.1.0
curl -fsSL https://github.com/extractumio/todobem/releases/latest/download/install.sh | sh   # a new install
```

## Versions

| | |
|---|---|
| State schema (`~/.todobem`) | 1 — unchanged, no migration |
| Agent protocol | 1 |

| Facts format | 16 |

A hub and an agent on v0.1.0 and v0.1.1 work together: same protocol and formats.
