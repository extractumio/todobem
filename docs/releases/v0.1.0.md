# todobem v0.1.0

The first release: a wall-clock profiler for AI coding-agent sessions, as one binary you install
without Go. Every later version installs over this one with `todobem upgrade`.

## Install

```sh
curl -fsSL https://github.com/extractumio/todobem/releases/latest/download/install.sh | sh
todobem
```

That installs the latest release; this one exactly:
`curl -fsSL https://github.com/extractumio/todobem/releases/download/v0.1.0/install.sh | TODOBEM_VERSION=v0.1.0 sh`.
The binary lands in `~/.todobem/bin/todobem`, checked against this release's `SHA256SUMS`; the
installer prints the `PATH` line to add. Builds: macOS on Apple Silicon (`darwin/arm64`) and
Linux x86-64 (`linux/amd64`).

## What it does

- **Inspect** — every Codex CLI and Claude Code session as lanes on one timeline (the main agent
  and each sub-agent), each tool call classified by a deterministic rule; the conversation as
  recorded; live sessions followed as they run.
- **Profile** — an exclusive partition of the wall clock that adds up to the elapsed time (model
  generation, build, test, release, infrastructure, waiting for workers, waiting for you, no
  telemetry), a second one by SDLC stage, retry groups, background processes, token usage.
- **Improve** — an Insights report over a period and a project: deterministic detectors, each
  with its denominator and the sessions it came from.
- **Fleet** — `todobem -agent` on other machines, answering a hub you pair with over pinned TLS.
- **Upgrade** — `todobem upgrade`, `todobem upgrade check`, `todobem upgrade rollback`.

Private by design: loopback only, a token-locked UI, no telemetry. The only outbound calls are
to agents you pair and, when you run it, `todobem upgrade` to this repository's releases.

## Known limits

- The first supported version: state from development builds is used as it is, not migrated;
  if a development-era `~/.todobem` misbehaves, remove it.
- An upgrade replaces the binary; restart todobem to run the new version. There is no service
  manager integration yet; the README has a sample systemd unit for an agent.
- No builds yet for Linux arm64, Intel macOS or Windows.
- Codex CLI 0.144+ stores inter-agent messages encrypted: a sub-agent's card says so instead of
  showing the prompt it was spawned with.
